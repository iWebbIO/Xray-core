# CLI compatibility fixtures

The four `mldsa65-*.txt` / `mlkem768-*.txt` files are complete stdout captures
from the repository's Go 26.9.9 reference executable. `zero` uses an all-zero
32-byte or 64-byte seed; `sequence` uses bytes `0, 1, ...` of the appropriate
length. Inputs are unpadded URL-safe base64. Tests compare the entire Rust
output, including key bytes, BLAKE3 digest, field labels and final LF.

`ech-sequence.txt` uses private bytes `0..31`, public name
`cloudflare-ech.com`, and the source's nine HPKE cipher suites. Python
`cryptography` generated the X25519 public key, Python `struct` independently
encoded the wire fields, and the Go `tls ech -i` command restored and printed
the captured ECH config list/server keys.

`ca.pem` is a fixed P-256 certificate generated by Go `tls cert` with
`-ca -domain=fixture.example -name="CLI Fixture" -org="Xray Rust Migration"`.
Its private key is not stored. The Go `tls hash` result for its complete DER
certificate is:

```text
d5fe79e9d06e38478a3fbb5ead57c498af09298747984fb88182a4f540c01244
```

All fixed crypto seeds here are public test values, never deployment keys.
